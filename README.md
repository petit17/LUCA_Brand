# LUCA Store — เว็บขายเสื้อของแบรนด์เอง

เว็บร้านค้าออนไลน์ที่ไม่มีค่าธรรมเนียมรายเดือนและไม่หักเปอร์เซ็นต์จากยอดขาย

| ส่วน | ใช้อะไร | ค่าใช้จ่าย |
|---|---|---|
| หน้าเว็บ | GitHub Pages (`https://petit17.github.io/LUCA_Brand/`) | ฟรี |
| ฐานข้อมูลออเดอร์ / หลังบ้าน | Google Sheets + Google Apps Script | ฟรี |
| เก็บรูปสลิป | Google Drive | ฟรี |
| รับเงิน | QR พร้อมเพย์แบบระบุยอด (เงินเข้าบัญชีร้านโดยตรง) | ฟรี |

## ระบบที่มีให้

- หน้าแรก, หน้ารวมสินค้า (กรองตามคอลเลกชัน/สี, เรียงราคา), หน้าสินค้า (เลือกสี/ไซซ์/จำนวน, แกลเลอรี, ตารางไซซ์)
- ตะกร้าสินค้า (จำไว้ในเครื่องลูกค้า) + แถบ “ซื้ออีก ฿xxx ส่งฟรี”
- Checkout: ที่อยู่จัดส่ง, เลือกขนส่ง, โค้ดส่วนลด, พร้อมเพย์ หรือเก็บเงินปลายทาง (COD)
- หน้าชำระเงิน: **QR พร้อมเพย์ที่ใส่ยอดให้อัตโนมัติ** + แนบสลิปในเว็บ
- ติดตามออเดอร์ด้วยเลขคำสั่งซื้อ + เบอร์โทร (แสดงสถานะและเลขพัสดุ)
- หลังบ้านเป็น Google Sheet: ออเดอร์ใหม่เข้าชีต + อีเมลแจ้งร้าน, สลิปเก็บใน Drive, ร้านแก้สถานะ/ใส่เลขพัสดุในชีต → ส่งอีเมลแจ้งลูกค้าอัตโนมัติ
- ฝั่งเซิร์ฟเวอร์คำนวณราคาซ้ำจาก `store.json` ลูกค้าจึงแก้ราคาจากหน้าเว็บไม่ได้

## ขั้นตอนเปิดร้าน (ประมาณ 15 นาที)

### 1. ใส่พร้อมเพย์ของร้าน — `config.js`

```js
PROMPTPAY_ID: "0812345678",          // เบอร์ที่ผูกพร้อมเพย์ หรือเลขบัตรประชาชน 13 หลัก
PROMPTPAY_NAME: "นาย ลูกา ใจดี",      // ชื่อบัญชีที่จะขึ้นตอนสแกน
```

ถ้ายังไม่ใส่ หน้าชำระเงินจะไม่แสดง QR (กันลูกค้าโอนผิดบัญชี)

### 2. ตั้งค่าหลังบ้าน (Google Sheets)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `LUCA Orders`
2. ที่เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิมออก แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs`
3. ตรวจ `CONFIG` ด้านบนไฟล์ว่า `STORE_JSON_URL` / `SITE_URL` ตรงกับเว็บจริง (ใส่ `OWNER_EMAIL` ได้ถ้าอยากให้แจ้งเตือนไปอีเมลอื่น)
4. เลือกฟังก์ชัน `setup` แล้วกด **Run** → กดอนุญาตสิทธิ์ (Sheets, Drive, Gmail)
   - สคริปต์จะสร้างชีต `Orders`, โฟลเดอร์ `LUCA Slips` ใน Drive และระบบอีเมลแจ้งลูกค้า
   - ต้องเปิดเว็บ (ขั้นตอนที่ 3) ก่อน `setup` ถึงจะโหลด `store.json` ได้
5. กด **Deploy → New deployment → ประเภท Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ใน `config.js`:
   ```js
   APPS_SCRIPT_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```

> ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้องไปที่ **Deploy → Manage deployments → แก้ไข → Version: New version** ทุกครั้ง

ถ้ายังไม่ได้ตั้งค่า `APPS_SCRIPT_URL` เว็บจะทำงานใน **โหมดทดลอง**: ลูกค้ายังสั่งซื้อและเห็น QR ได้ แต่ออเดอร์จะไม่เข้าชีต ลูกค้าต้องกด “คัดลอกสรุปคำสั่งซื้อ” แล้วส่งให้ร้านทางแชทแทน

### 3. เปิดเว็บ

เปิด GitHub Pages (Settings → Pages → Deploy from branch → `main` / root)
เว็บจะอยู่ที่ `https://petit17.github.io/LUCA_Brand/`

## การจัดการร้านประจำวัน

**ออเดอร์ใหม่** → อีเมลแจ้ง + ขึ้นแถวใหม่ในชีต `Orders` (สถานะ `รอชำระเงิน`)

**ลูกค้าแนบสลิป** → อีเมลแจ้ง + สถานะเปลี่ยนเป็น `รอตรวจสอบสลิป` + ลิงก์สลิปอยู่ในคอลัมน์ “สลิป”
เช็คยอดในแอปธนาคารให้ตรงกับคอลัมน์ “ยอดรวม” แล้วเปลี่ยนสถานะเป็น `ชำระแล้ว`

**ส่งของ** → ใส่ “บริษัทขนส่ง” และ “เลขพัสดุ” แล้วเปลี่ยนสถานะเป็น `จัดส่งแล้ว`
ลูกค้าที่ใส่อีเมลไว้จะได้รับอีเมลแจ้งเลขพัสดุอัตโนมัติ และเห็นเลขพัสดุในหน้า “ติดตามออเดอร์”

สถานะที่ใช้ได้: `รอชำระเงิน` · `รอตรวจสอบสลิป` · `ชำระแล้ว` · `เก็บเงินปลายทาง` · `กำลังเตรียมจัดส่ง` · `จัดส่งแล้ว` · `สำเร็จ` · `ยกเลิก`

## แก้สินค้า ราคา ค่าส่ง คูปอง — `data/store.json`

- **เพิ่มสินค้า**: คัดลอกก้อน `{ ... }` ใน `products` แล้วแก้ `id` (ภาษาอังกฤษ ไม่มีเว้นวรรค), `name`, `price`, `colors` และรูป
- **รูปสินค้า**: วางไฟล์ไว้ใน `assets/img/` (แนะนำรูปสี่เหลี่ยมจัตุรัส ประมาณ 900×900px) แล้วใส่ path ใน `images` รูปแรกคือรูปหลัก
- **ราคาเต็ม/ขีดฆ่า**: ใส่ `compareAt` (ลบออกถ้าไม่ต้องการ)
- **ป้าย**: `badge` เช่น `"New"`, `"Best Seller"`
- **สินค้าหมด**: `"soldOut": ["Black/M", "White"]` (สี/ไซซ์ หรือทั้งสี)
- **ค่าส่ง**: `shipping`, ส่งฟรีขั้นต่ำ `freeShippingMin` (ใส่ `0` ถ้าไม่มีส่งฟรี)
- **COD**: `"cod": { "enabled": true, "fee": 30 }` ปิดได้ด้วย `false`
- **คูปอง**: `coupons` ใช้ `type` เป็น `percent` (ลดเปอร์เซ็นต์) หรือ `fixed` (ลดเป็นบาท) และ `minSubtotal` เป็นยอดขั้นต่ำ
  ไฟล์นี้เปิดอ่านได้สาธารณะ จึงไม่ควรใช้เก็บโค้ดลับ

หลังแก้ `store.json` ฝั่ง Apps Script จะใช้ข้อมูลใหม่ภายใน 5 นาที (มี cache)

⚠️ **ราคา (390 บาท) และรายละเอียดสินค้าในไฟล์ตอนนี้เป็นค่าตัวอย่าง** ควรตรวจและแก้ให้ตรงกับของจริงก่อนเปิดขาย
เช่น เพิ่มสเปคผ้าใน `details` และตรวจตารางไซซ์ใน `sizeChart`

## โครงสร้างไฟล์

```
LUCA_Brand/
├── index.html            หน้าเว็บ (เป็น single page ใช้ #/ ในการเปลี่ยนหน้า)
├── config.js             ⚙️ ตั้งค่าร้าน (พร้อมเพย์, URL หลังบ้าน, โซเชียล)
├── data/store.json       🛍️ สินค้า / ค่าส่ง / คูปอง / ตารางไซซ์
├── css/style.css
├── js/app.js             หน้าร้าน + ตะกร้า + checkout + ติดตามออเดอร์
├── js/pricing.js         สูตรคำนวณราคา (โค้ดเดียวกับใน Code.gs)
├── js/promptpay.js       สร้าง QR พร้อมเพย์ (มาตรฐาน EMVCo)
├── js/vendor/qrcode.js   ไลบรารีวาด QR (MIT, Kazuhiko Arase)
├── assets/img/           รูปสินค้า / โลโก้
└── apps-script/Code.gs   🧾 หลังบ้าน (วางใน Google Apps Script)
```

ทดสอบบนเครื่อง: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000
